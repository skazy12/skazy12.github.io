# Portafolio de Omar Gustavo Rodriguez Becerra

Sitio personal bilingüe orientado a presentar experiencia en backend, desarrollo full-stack e ingeniería de datos.

## Desarrollo local

No requiere dependencias ni compilación. Desde la raíz del repositorio:

```powershell
python -m http.server 4173
```

Después, abrir `http://localhost:4173`.

## Publicación

GitHub Pages publica directamente la rama `main` desde la raíz del repositorio.
