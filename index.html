01

Full-stack · E-commerce

GameMarket

Marketplace de licencias digitales con tres roles, inventario sensible y un checkout que debe mantener consistencia incluso ante compras concurrentes.

Reto
Evitar entregar una clave dos veces y conservar un historial inmutable del pedido.
Solución
Clean Architecture, transacciones PostgreSQL con bloqueo de filas, cookies HttpOnly y autorización por roles.
Evidencia
33 pruebas backend y 19 pruebas frontend documentadas en el repositorio.

  • React 19
  • TypeScript
  • PostgreSQL 16
  • Docker

Enterprise · Full-stack

IT Operations Hub

Aplicación interna ficticia que cubre el ciclo completo de una incidencia: reporte, clasificación, asignación, resolución, SLA y auditoría.

03

Data Engineering · Risk

Fraud Pattern Detector

Pipeline batch para ingerir transacciones sintéticas, medir su calidad y detectar patrones de riesgo mediante reglas explicables.

Reto
Separar errores de calidad de señales de fraude y conservar un recorrido reproducible.
Solución
Capas Bronze, Silver y Gold, cuarentena de registros, cinco reglas temporales y scoring de riesgo.
Evidencia
Dataset reproducible de 50.004 transacciones y siete suites de prueba documentadas.
  • Scala 3
  • Apache Spark
  • Python
  • Parquet
  • Plotly.js

Developer Tool · Browser-only

DOCODE

Herramienta web que analiza repositorios públicos o carpetas locales y genera un contexto estructurado para documentación, revisión de código o trabajo con LLMs.
